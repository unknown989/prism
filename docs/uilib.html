Prism UILib

A UI library built on Prism. Immediate-mode style: you call widget functions each frame. Supports layout panels, basic and advanced controls, menus, dialogs, and more.

Core types

  • uilib_point_t (alias position_t) – x, y
  • uilib_size_t (alias prism_size_t) – width, height
  • uilib_rectangle_t (alias rect_t) – position, size
  • uilib_color_t (alias color_t) – r, g, b, a

Helpers: uilib_point(x,y), uilib_size(w,h), uilib_rect(x,y,w,h).

EventArgs

  • uilib_mouse_event_args_t – x, y, button, pressed
  • uilib_key_event_args_t – key, pressed
  • uilib_paint_event_args_t – window, clip_rect

Font, Brush, Pen

  • uilib_font_t – size (scale for Prism built-in font)
  • uilib_brush_t – color (for fills)
  • uilib_pen_t – color, width (for outlines)

Application, Window

uilib_app_create(prism_size_t size, uilib_point_t pos)
Creates application and main window.
uilib_app_run / uilib_app_exit
Lifecycle helpers.

Timer

uilib_timer_start(t, interval_ms)
Start a timer with a tick callback.
uilib_timer_tick(t, now_ms)
Call each frame; invokes on_tick when interval elapsed.

Frame begin

void uilib_begin(uilib_ctx_t *ctx, window_t *window, const uilib_theme_t *theme);
Call once per frame before any widgets. Updates mouse, theme.

Layout panels

uilib_stack_begin / uilib_stack_next
StackPanel – vertical or horizontal, returns next child rect.
uilib_grid_begin / uilib_grid_cell
Grid – fixed columns and rows.
uilib_dock_begin / uilib_dock_add
DockPanel – dock Top, Bottom, Left, Right, Fill.
uilib_wrap_begin / uilib_wrap_next
WrapPanel – flow layout with fixed item size.
uilib_rectangle_t r;
uilib_stack_begin(&ui, uilib_rect(20, 40, 180, 200), UILIB_ORIENT_VERT, 4);
if (uilib_stack_next(&ui, 28, &r)) uilib_button(&ui, r, "Click");

Containers

uilib_panel(ctx, rect)
Filled panel with border.
uilib_group_box(ctx, rect, title)
Grouped panel with title.
uilib_scroll_viewer_begin / uilib_scroll_viewer_end
ScrollViewer – pass uilib_scroll_state_t with content/view heights.

Basic widgets

bool uilib_button(ctx, rect, label)
Returns true on click.
void uilib_label(ctx, pos, text, dim)
Text only. dim=true for muted color.
bool uilib_checkbox(ctx, rect, label, uilib_checkbox_state_t *state)
Toggle. state->checked.
bool uilib_radiobutton(ctx, rect, label, value, uilib_radiobutton_state_t *state)
Radio. state->selected.

TextBox

void uilib_textbox(ctx, rect, uilib_textbox_state_t *state)
Single-line text. state: buf, len, caret, scroll_x. Ctrl+H = backspace.

ListBox, ComboBox

bool uilib_listbox(ctx, rect, uilib_listbox_state_t *state)
state: items[], count, selected, scroll_offset.
bool uilib_combobox(ctx, rect, uilib_combobox_state_t *state)
state: items[], count, selected, dropped.

ScrollBar, ProgressBar, Slider

bool uilib_scrollbar(ctx, rect, vertical, uilib_scrollbar_state_t *state)
state: value, min_val, max_val, page_size.
void uilib_progressbar(ctx, rect, uilib_progressbar_state_t *state)
state->value 0..1.
bool uilib_slider(ctx, rect, vertical, uilib_slider_state_t *state)
state->value 0..1. Returns true when changed.

PictureBox, TabControl, Splitter

void uilib_picture_box(ctx, rect, uilib_image_t *img)
Displays image or placeholder.
uilib_tab_control_begin / uilib_tab_control_end
TabControl. Pass uilib_tab_state_t: tabs[], count, selected.
void uilib_splitter(ctx, rect, vertical, uilib_splitter_state_t *state)
Draggable splitter. state: pos, dragging.

Menus

bool uilib_menu_strip(ctx, rect, uilib_menu_strip_t *strip, int *out_id)
MenuStrip – horizontal menu bar.
bool uilib_context_menu(ctx, uilib_context_menu_t *menu, int *out_id)
ContextMenuStrip – popup. menu->open, menu->position.
void uilib_status_strip(ctx, rect, text)
StatusStrip – status bar.

Dialogs

Platform-dependent. Windows: native dialogs. Linux/macOS: stubs return false/none.

uilib_message_box(title, message, buttons)
OK, OK_CANCEL, YES_NO. Returns result.
uilib_open_file_dialog / uilib_save_file_dialog
File picker. Fill filename[], filter.
uilib_folder_browser_dialog
Folder picker. path[].
uilib_color_dialog / uilib_font_dialog
Color or font picker.

PropertyGrid

void uilib_property_grid(ctx, rect, uilib_property_grid_t *grid)
Simple property list. props[].name, type (INT/FLOAT/BOOL/STRING), value.

Image, Icon, Cursor

  • uilib_image_t – alias image_t. Use load_bmp() from Prism.
  • uilib_icon_t – wrapper for image.
  • uilib_cursor_type_t – placeholder (no native cursor without platform code).

Demo

Build and run:

make uilib_demo
./uilib_demo

The demo showcases: StackPanel layout, Button, CheckBox, RadioButton, TextBox, Slider, ProgressBar, ListBox, ComboBox, TabControl, StatusStrip.

Build

Link with -luser32 -lgdi32 on Windows. Add -lcomdlg32 -lshell32 for dialogs.

On Linux: -lX11 -lm. Dialogs are stubbed.
